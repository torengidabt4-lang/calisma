# Ekran - Uzaktan Masaüstü Uygulaması

Visual Studio 2022 ile yapılmış Windows uzaktan masaüstü kontrol uygulaması.

## Özellikler
- 📺 Ekran Görüntüsü Alma ve Gösterme
- 🖱️ Mouse Kontrolü (Hareket, Tıklama)
- ⌨️ Klavye Kontrolü (Yazı, Tuşlar)
- 🎨 Modern WPF Arayüzü
- ⚙️ .NET Framework 4.8

## Sistem Gereksinimleri
- Windows 7 ve üzeri
- .NET Framework 4.8
- Visual Studio 2022

## Kurulum
1. Depoyu klonla: `git clone https://github.com/torengidabt4-lang/calisma.git`
2. Visual Studio 2022'de açılış dosyasını aç: `Ekran.sln`
3. Çözümü derle: `Ctrl + Shift + B`
4. Uygulamayı çalıştır: `F5`
